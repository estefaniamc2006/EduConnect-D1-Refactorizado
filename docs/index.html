Prototipo académico · Módulo D1

Seguridad de datos estudiantiles

EduConnect es un prototipo desarrollado con Python y Flask para demostrar el control de acceso y la protección de información académica mediante los patrones de diseño Proxy y Decorator.

Ver código en GitHubConocer la solución

Proxy

Verifica el rol del usuario antes de permitir consultas o modificaciones y registra los accesos permitidos y denegados.

Decorator

Agrega cifrado y descifrado a las operaciones del repositorio de información académica.

Contraseñas

Protege las contraseñas mediante hash con scrypt y conserva un historial limitado para evitar su reutilización.

Importante: esta página es la presentación estática del proyecto. GitHub Pages no ejecuta el servidor Flask ni la base de datos SQLite; para usar el sistema web en línea se requiere desplegar el backend en un servicio compatible.
